# The ambition booster

Use on **important** jobs only. Three questions turn "do this task" into "get this result, the
way a top professional would, checked by something other than the model".

## Contents

- Two add-on prompts

## The three questions

| Question | Changes this template line |
|---|---|
| **Aim higher:** what is the result behind this request? What should be true when it's finished? | `Outcome` |
| **Go deeper:** how would a top professional do this, starting from which original source, with which tools? | `Methods and tools`, `Inputs`, `Stretch target` |
| **Go wider:** which other fields would spot something this one misses? | `Methods and tools` (the team), `Who checks it` |

## Aim higher: ask for the result

- A task is the user's guess at how to get a result. Name the result too, so Claude can aim at it.
- "Fill in this slide template" → result: "the client says yes in the meeting".
- "Fix this bug" → result: "customers can check out without errors".
- Strong signs this applies: people will meet to discuss the work, or the same request keeps coming back.
- A request that keeps coming back is the best target. Asking for the result can turn it into a repeatable workflow, so the user stops asking.
- **Check access.** A bigger goal only works if Claude can reach the data and tools it needs. If it can't, say what's missing instead of guessing.

## Go deeper: the professional's way

- **Methods, not job titles.** "Act like an expert" mostly changes the wording. Name the method instead: a spreadsheet model rather than a bullet list; a page-speed test rather than "make it fast". If the user doesn't know the methods, ask Claude to list the ones a professional would use, then use them.
- **Original source.** Work from the full data, transcript or export, not a summary of it.
- **Stretch target.** Offer a bold, specific goal alongside the safe one, and treat it as worth attempting. If Claude pushes back, ask what would have to be true to reach it, and try that route.
- **Test a belief.** "We think most refunds come from late deliveries. Check that against the full order export."
- **Look for the surprise.** "While you're in the data, tell me the one pattern I'd least expect."

## Go wider: bring in other fields

- **Describe what it must do, not what it is.** Not "a pricing page", but "help a nervous first-timer feel safe enough to sign up". The action shows which fields can help: a coach who calms beginners, a designer, a skeptical buyer.
- **Build a team.** Pick a few specialists from different fields. Make two of them critics whose only job is finding problems.
- **Borrow skills, not personalities.** Ask Claude to apply what each specialist knows (their checklists, their tests, their questions), not to imitate how they talk. Imitation adds flavour, not quality.
- **It costs more.** A team uses several times more of the plan than one reply (a rough estimate). Save it for work that matters, or for spare usage before the reset.

## When not to stretch

- Quick, clear requests and casual chat: skip all of this.
- Taste-led creative work (brand voice, art direction): keep the user's direction. Only borrow research and a critic.
- Anything that sends, publishes, spends or changes live accounts: ambition never adds permission.

## Two add-on prompts

Offer these when the user wants to push a task further.

**Go deeper**
```
Hold on before you start. Give me three short lists:
1. What a top professional would add to this that I left out.
2. The original material they'd want from me (files, data, examples), not a summary.
3. How we'll prove the result works, using something other than your opinion.
Then show me an improved version of my request that includes all three, and wait for my OK.
```

**Expert team**
```
Put together a small team for this: four or five specialists from different fields, plus two
critics who only hunt for weaknesses. For each person, write one line on the checks or methods
they'd bring. Then do the work applying every one of those methods, and finish with the critics'
top objections and how you dealt with each. Use their skills; don't imitate their voices.
```
